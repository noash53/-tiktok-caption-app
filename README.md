# TikTok Caption Mobile

גרסת מובייל לאייפון/אנדרואיד.

## איך משתמשים בטלפון
האפליקציה צריכה להיות מפורסמת באינטרנט. הדרך הכי פשוטה:

1. מעלים את התיקייה ל-GitHub.
2. נכנסים ל-Streamlit Community Cloud.
3. בוחרים את הריפו ואת `app.py`.
4. אחרי הפרסום מקבלים קישור.
5. באייפון: פותחים את הקישור ב-Safari → שיתוף → "הוסף למסך הבית".

אחרי זה האפליקציה תופיע כאייקון במסך הבית.

## מה היא עושה
- מקבלת קישור של TikTok.
- תומכת גם בקישורי vt.tiktok.com ו-vm.tiktok.com.
- שולפת את ה-caption / התיאור הציבורי.
- מציגה אותו בתיבה נוחה לקריאה.
- כוללת כפתור העתקה.

## מגבלה
TikTok עשויה לא להחזיר מידע על סרטון פרטי, מוסר, מוגבל או כזה שאינו זמין דרך oEmbed.
